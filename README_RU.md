# Deathwatch RU — единая русифицированная система для Foundry VTT

Это отдельная, самостоятельная система Foundry VTT с ID `deathwatch-ru`. Она устанавливается рядом с оригинальной Deathwatch и включает полный набор runtime-файлов системы, исходные игровые правила и скомпилированные компендиумы.

## Важное исправление листов в v0.0.2-ru.18

При диагностике найдено две проблемы. Во-первых, оригинальные листы регистрировались под ID `deathwatch`, а русская сборка использует `deathwatch-ru`; теперь ID регистрации исправляется и проверяется. Во-вторых, глобальный перевод всех фрагментов в обратных кавычках захватывал inline-код в комментариях и переводил ключевые слова JS (например, `export let` превращалось в `экспорт пусть`). Этот этап удалён; переводятся только распознаваемые пользовательские строки и конкретные шаблонные поля. Теперь сборка проверяет синтаксис каждого JavaScript-модуля, пути к шаблонам/файлу навыков и наличие критических HTML-шаблонов и скомпилированных компендиумов в конечном ZIP. Если проверка не проходит, ZIP не публикуется.

## Что входит в установочный пакет

- Полный интерфейс системы: листы персонажей и противников, вкладки, кнопки, поля, подписи, подсказки и диалоги.
- Навыки, характеристики, уровни сложности и подписи, используемые в сообщениях о проверках.
- Динамические боевые карточки и уведомления.
- Компендиумы: оружие, броня, боеприпасы, снаряжение, таланты, особенности, ордена, специализации, импланты, кибернетика, психические силы, критические эффекты, травмы, противники, макросы и таблицы.
- Локализация отображаемых значений в полях правил и модификаторов без изменения исходных кодов, используемых логикой игры.

## Как создаётся перевод

Перед упаковкой сборка анализирует исходники, HTML-шаблоны и JSON записи компендиумов, применяет словарь терминов Warhammer 40,000 и машинный перевод к текстовым фрагментам, затем компилирует `packs-source` в формат, который использует Foundry. В журнале сборки есть проверка строк, которые сканер обнаруживает как полностью английские.

**Важно:** автоматическая проверка не заменяет проверку в самом Foundry и не гарантирует идеальную литературную вычитку каждой строки. Имена собственные и узкоспециальные термины могут требовать правки; после обновления рекомендуется проверить лист персонажа, предмет оружия, психическую силу, карточку боя и несколько записей из каждого компендиума.

## Установка через манифест

В Foundry VTT откройте **Управление системами → Установить систему** и вставьте ссылку:

```
https://raw.githubusercontent.com/DaniilDeyron/DeathwatchRUSsystem/main/system.json
```

Манифест направляет установщик на ZIP последнего успешного релиза:

`https://github.com/DaniilDeyron/DeathwatchRUSsystem/releases/latest/download/deathwatch-ru.zip`

## Сборка новой версии

Откройте вкладку [Actions](https://github.com/DaniilDeyron/DeathwatchRUSsystem/actions) и выберите **Build and publish Deathwatch RU**. Workflow скачивает upstream build-скрипты, обрабатывает тексты, компилирует компендиумы и прикрепляет единственный ZIP системы к GitHub Release. Исходники и папка сборки не нужны пользователю при установке.
