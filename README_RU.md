# Deathwatch RU — отдельная система для Foundry VTT

Это отдельная версия системы с идентификатором `deathwatch-ru`. Она задумана для установки рядом с оригинальной системой `deathwatch`.

## Статус перевода
Это пока **начальный слой локализации**, а не полный перевод. Значительная часть названий/описаний предметов, талантов, психических сил, противников и критических эффектов остаётся на английском.

## Установка через манифест Foundry
После создания первого GitHub Release откройте Foundry VTT → **Управление системами → Установить систему** и вставьте:

```
https://raw.githubusercontent.com/DaniilDeyron/DeathwatchRUSsystem/main/system.json
```

Манифест указывает на ZIP из последнего релиза:
`https://github.com/DaniilDeyron/DeathwatchRUSsystem/releases/latest/download/deathwatch-ru.zip`

## Публикация установочного архива
В репозитории добавлен workflow **Build and publish Deathwatch RU**. Он:
1. Берёт исходники из репозитория.
2. Использует build-скрипты оригинального проекта для компиляции `packs-source` в готовые компендиумы Foundry.
3. Упаковывает готовую систему в `deathwatch-ru.zip`.
4. Прикрепляет архив к GitHub Release.

Чтобы выпустить первую версию, откройте вкладку **Actions**, выберите **Build and publish Deathwatch RU**, нажмите **Run workflow** и укажите тег релиза, например `v0.0.2-ru.1`.

Не загружайте архив в корень репозитория — workflow создаёт и прикрепляет его к релизу, обходя ограничение браузерной загрузки файлов.
