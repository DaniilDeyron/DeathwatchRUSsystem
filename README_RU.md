# Deathwatch RU — отдельная система для Foundry VTT

Это отдельная версия системы с идентификатором `deathwatch-ru`. Она предназначена для установки рядом с оригинальной системой `deathwatch`.

## Как работает русификация

Workflow **Build and publish Deathwatch RU** запускает автоматический перевод перед сборкой установочного ZIP:
- названия навыков, характеристик, сложностей и других подписей, заданные в исходном коде;
- текст кнопок, вкладок, подсказок и диалогов в HTML-шаблонах и пользовательских интерфейсных строках;
- названия и описания предметов, талантов, психических сил, особенностей, противников, критических эффектов, результатов таблиц и других записей в исходных JSON компендиумов;
- преимущества и требования талантов, описания проклятий орденов, короткие описания, бонусы, требования и подписи источников;
- текст динамических сообщений боя, карточек в чате и подсказок, которые формируются из шаблонных строк;
- подписи групп внутри компендиумов;
- отдельные словари названий характеристик, используемые программным API и формулами проверок;
- вручную закреплённые переводы часто встречающихся терминов вселенной Warhammer 40,000 и названий орденов;
- локализованные варианты классов оружия, типов урона, типов действий, уровня известности, диапазонов и других перечислений в тех местах, где это только отображение — сами значения, используемые правилами, остаются прежними.

Перевод выполняется машинным переводчиком Google во время сборки. Скрипт дополнительно ищет естественно-языковые строки и в нестандартных полях данных, а не только в заранее заданном списке ключей. Игровые коды, формулы, пути и механические значения защищены от перевода. Значения, используемые внутренней логикой правил (например, коды типов урона и категорий оружия), сохраняются; переводятся их пользовательские подписи и отображаемые поля.

**Важно:** это автоматический перевод, а не вычитанная редактором локализация. Термины Warhammer 40,000, имена собственные и отдельные строки интерфейса могут потребовать проверки. Если в журнале GitHub Actions указаны ошибки перевода, соответствующие фрагменты могут остаться на английском.

## Создание установочного релиза

1. Откройте вкладку [Actions](https://github.com/DaniilDeyron/DeathwatchRUSsystem/actions).
2. Выберите **Build and publish Deathwatch RU**.
3. Нажмите **Run workflow**, оставив ветку `main`.
4. В поле тега укажите, например, `v0.0.2-ru.1`.
5. Нажмите **Run workflow** и дождитесь зелёной галочки. Для сопровождающего автоматический запуск также доступен коммитом с префиксом `[build-ru]`.
6. Проверьте, что в [Releases](https://github.com/DaniilDeyron/DeathwatchRUSsystem/releases) прикреплён файл `deathwatch-ru.zip`.

Сборка компилирует исходные `packs-source` в готовые компендиумы Foundry; исходные данные не включаются в установочный ZIP. Архив создаётся с `system.json` в корне, как ожидает установщик.

## Установка в Foundry VTT

В Foundry откройте **Управление системами → Установить систему** и вставьте URL манифеста:

```
https://raw.githubusercontent.com/DaniilDeyron/DeathwatchRUSsystem/main/system.json
```

Манифест указывает на ZIP последнего релиза:

`https://github.com/DaniilDeyron/DeathwatchRUSsystem/releases/latest/download/deathwatch-ru.zip`

До публикации первого релиза Foundry не сможет скачать ZIP.
